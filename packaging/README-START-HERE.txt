感谢你下载使用 Invoice Hub！
本发布包包含了运行应用程序所需的全部核心运行环境与依赖。

────────────────────────────────────────────────────────────────────────────────
 快速开始
────────────────────────────────────────────────────────────────────────────────

  1. 将此 ZIP 压缩包解压到任意文件夹，例如：
       C:\InvoiceHub\

  2. 双击  InvoiceHub.exe  即可直接启动应用程序（秒级启动，首帧响应 < 2秒）。

  3. 首次启动时，点击  ⚙ 系统设置，根据向导：
       a. 选择您的邮箱类型（如 QQ邮箱、网易邮箱、企业邮箱等）
       b. 输入您的邮箱地址
       c. 输入您的 IMAP 邮箱授权码
          （QQ邮箱获取方式：登录网页版邮箱 ➔ 设置 ➔ 账户 ➔ 开启 IMAP ➔ 生成授权码）
       d. 点击测试连接 — 绿色勾选即代表连接成功！

  4. 点击  📧 扫描邮箱  即可开始自动扫描并导入邮箱中的发票。

  5. 使用  🚀 一键导出  可一键打包报销所需的 Excel 汇总表及 PDF 附件归档包。

────────────────────────────────────────────────────────────────────────────────
 浏览器发票下载与智能降级说明
────────────────────────────────────────────────────────────────────────────────

  部分发票服务商（如中国电信等）需要通过浏览器模拟抓取的方式下载发票。
  为了保持极简的包体积，本包**没有内置 400MB 庞大的 Chromium 浏览器**。

  Invoice Hub 采用了先进的**智能降级探测技术**：
    1. 当触发浏览器下载时，程序会自动寻找系统自带的 **Microsoft Edge** 或 **Google Chrome** 浏览器。
    2. 绝大多数现代 Windows 系统已内置 Microsoft Edge，因此**您无需进行任何额外安装或配置**，即可直接享受完整的网页下载功能！
    3. 如果系统浏览器启动遇到异常，您也可以在 `config.json` 的 `playwright.channel` 中自定义配置您的浏览器通道。

────────────────────────────────────────────────────────────────────────────────
 数据与隐私安全存放路径
────────────────────────────────────────────────────────────────────────────────

  本程序为完全的**本地优先 (Local-First)** 架构：
  所有本地数据（发票数据库、下载的附件文件、导出文件和日志）默认安全隔离存储在 Windows 标准应用数据目录中：

    %APPDATA%\InvoiceHub\          — 您的 Windows 用户数据存储根目录
      invoices.db                  — 本地 SQLite 数据库（存储所有发票元数据）
      attachments\                 — 所有下载的发票 PDF/OFD 物理附件
      logs\                        — 应用程序运行日志（按运行周期滚动）

  您的邮箱授权码将通过 Windows 凭据管理器 (`Credential Manager`) 安全加密存储在操作系统硬件级别的安全区域中，绝不会以任何明文形式保存在任何本地文件或日志中。

────────────────────────────────────────────────────────────────────────────────
 高级配置与自定义
────────────────────────────────────────────────────────────────────────────────

  本程序专为开箱即用设计，**普通用户完全无需手动复制或配置 `config.json`**，主路径的设置向导会指导您完成一切。

  对于高级开发与自定义需求，本包包含一个配置模板文件 `config.example.json`。您可以根据需要复制并命名为 `config.json`（存放于 %APPDATA%\InvoiceHub\ 目录或程序根目录下），来自定义以下高级属性：
    • IMAP 服务器与端口（默认：imap.qq.com:993）
    • 扫描的邮件文件夹（默认：INBOX）
    • 扫描追溯的月份数（默认：3个月）
    • AI 分类服务商及 API Key
    • 自定义发票品类与扫描关键字
    • 浏览器通道配置 `playwright.channel`

  说明（`playwright.channel` 可选值）：
    - `"auto"`（默认）：自动探测，依次尝试环境中已有的默认 Chromium ➔ 系统 Google Chrome ➔ 系统 Microsoft Edge。普通用户无需安装 Playwright Chromium。
    - `"msedge"`：强制使用系统自带的 Microsoft Edge。
    - `"chrome"`：强制使用系统中安装的 Google Chrome。
    - `"chromium"`：仅限高级用户使用，需要您自行通过命令行 `playwright install chromium` 安装 Playwright Chromium。


────────────────────────────────────────────────────────────────────────────────
 隐私声明
────────────────────────────────────────────────────────────────────────────────

  • 默认状态下，程序绝不会向任何第三方云端上传您的发票文件或邮件内容。
  • 若开启 AI 分类，程序也仅会将脱敏后的邮件主题与发信人名称发送至您指定的 AI 接口，绝不会上传邮件正文或发票文件附件。
  • 您的 IMAP 邮箱密码/授权码绝不会离开您的本地计算机。
