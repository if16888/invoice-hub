### Packaged mobile HTTP evidence limitation and waiver

The candidate package was started with an isolated runtime helper, but the
current Windows Computer Use session could not expose a targetable visible Qt
window for that isolated child. Its launch approval also timed out once. No
real `POST /api/upload/<token>` was therefore claimed, and no direct
`owner.save_uploads()` or mocked completion was substituted.

The release owner explicitly waives this manual packaged-mobile-HTTP
measurement for this candidate. This is an acceptance waiver, not a test
pass: Android/browser/LAN compatibility and a real packaged multipart POST
remain unmeasured and must be validated separately before treating those
behaviors as verified.
