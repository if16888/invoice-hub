# Invoice Hub v0.1.0 - Windows x64

Invoice Hub is a local-first invoice and reimbursement evidence organizer for personal expense preparation.

它不是企业费控系统，也不替代 Concur、飞书、钉钉、合思等报销平台。它专注于提交报销前的个人整理环节：收集、去重、审核、归组和导出资料包。

## Download

- `InvoiceHub-Setup-v0.1.0.exe`: Windows per-user installer, no administrator permission required.
- `InvoiceHub-windows-x64-v0.1.0.zip`: portable onedir package.
- `checksums.txt`: SHA256 checksums for the release assets.

## Current Capabilities

- Desktop review workbench for invoice list review, field editing, document preview, review status, and claim group actions.
- IMAP mailbox scanning for QQ, 163/126, and custom IMAP settings.
- Local import for PDF, OFD, images, and ZIP files.
- Mobile upload entry for collecting invoice and evidence files from a phone on the local network.
- Claim group export with Excel ledger, manifest, and attachment package.
- Redacted diagnostics package for safer issue feedback.

## Privacy Reminder

- Invoice files, receipts, email bodies, PDF text, images, SQLite databases, and Excel exports stay local by default.
- AI classification is disabled by default. If explicitly enabled, only masked email subject and sender metadata are sent.
- Do not upload real invoices, receipts, databases, Excel reimbursement packages, mailbox authorization codes, API keys, full download links, or private financial data to GitHub Issues.

## Start From Source

```powershell
pip install -r requirements.txt
pip install -r requirements-desktop.txt
python -m scripts.invoice_fetch desktop
```

Command-line help:

```powershell
python -m scripts.invoice_fetch --help
```

## Known Limits

- This is an early preview release; test first with a small redacted sample set.
- Parsed fields still need manual review before reimbursement submission.
- No enterprise approval workflow, cloud sync, automatic reimbursement, or automatic submission to Concur, 飞书, 钉钉, 合思, or similar platforms.
- The uninstaller does not remove user runtime data by default.
- This release does not bundle Playwright Chromium browser binaries; it uses an installed Microsoft Edge or Google Chrome when browser download automation is needed.
