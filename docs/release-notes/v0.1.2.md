# Invoice Hub v0.1.2 - Windows x64

Patch release focused on review workflow fixes, deleted-invoice recovery, public documentation cleanup, and Windows package readiness.

## What's changed

- Added buyer name editing in the invoice review form.
- Persisted `buyer_name` through the invoice update path.
- Added dirty tracking and immediate buyer warning refresh after editing buyer name.
- Restored soft-deleted invoices when re-importing the same invoice or same uploaded file.
- Tightened deleted-invoice restore matching to avoid restoring a different seller with the same invoice number and amount.
- Aligned public docs and issue templates with the v0.1.1/v0.1.2 release flow.
- Documented Windows package and winget readiness.
- Recorded v0.1.1 Windows package validation results as the baseline for v0.1.2 release preparation.
- Kept GitHub Releases as the primary distribution channel.

## Release artifacts

- `InvoiceHub-Setup-v0.1.2.exe`: Windows per-user installer, no administrator permission required.
- `InvoiceHub-windows-x64-v0.1.2.zip`: portable onedir package.
- `checksums.txt`: SHA256 checksums for both artifacts.

## Deferred

The following items are intentionally not included in v0.1.2:

- Buyer tax ID mismatch validation.
- Buyer preset / reimbursement profile management.
- Multi-currency expense support.
- winget submission.
- GitHub Packages publishing.
- Enterprise expense-system submission automation.

## Privacy reminder

Please do not upload real invoices, receipts, itineraries, bank slips, mailbox screenshots, SQLite databases, Excel reimbursement packages, mailbox authorization codes, API keys, cookies, or full download links to public issues.

Use the redacted diagnostics package generated by Invoice Hub when reporting bugs.
