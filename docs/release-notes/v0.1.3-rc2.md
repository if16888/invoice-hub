# Invoice Hub v0.1.3-rc2 - Windows x64

Patch release focused on review-workbench context preservation, release metadata refresh, and README alignment.

## What's changed

- Preserved the current selection and table position after delete, restore, claim link/unlink, reparse, and redownload actions in the invoice review workbench.
- Kept the context-preservation wording in the README concise and aligned with the actual UI behavior.
- Bumped the application version metadata and public README release table to `v0.1.3-rc2`.

## Release artifacts

- `InvoiceHub-Setup-v0.1.3-rc2.exe`: Windows per-user installer, no administrator permission required.
- `InvoiceHub-windows-x64-v0.1.3-rc2.zip`: portable onedir package.
- `checksums.txt`: SHA256 checksums for both artifacts.

## Privacy reminder

Please do not upload real invoices, receipts, itineraries, bank slips, mailbox screenshots, SQLite databases, Excel reimbursement packages, mailbox authorization codes, API keys, cookies, or full download links to public issues.

Use the redacted diagnostics package generated by Invoice Hub when reporting bugs.
