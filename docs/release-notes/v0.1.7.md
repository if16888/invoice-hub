# Invoice Hub v0.1.7 — Release notes

> Status: **Stable — published on 2026-08-25.** The current official release is
> [Invoice Hub v0.1.7](https://github.com/if16888/invoice-hub/releases/tag/v0.1.7).

## What's changed

- **Faster normal shutdown:** the accepted Windows shutdown path removes the
  inactive mobile-firewall wait from normal close. The previous native baseline
  was approximately 11–12 seconds; the accepted Phase 2A path is at about the
  one-second level in the measured scenarios. This is an observed release
  result, not an absolute timing guarantee.
- **Completion result refresh:** mobile completion now performs one
  authoritative invoice-list refresh after installing the latest review scope;
  Overview, Imports, and Settings refresh lazily when those pages are opened.
  Local import updates its result list before showing the completion message.
  Synthetic continuous A/B completion P95 improved from 408.43 ms to 91.80 ms.
  Native visible-Qt completion latency was **not measured / owner-waived** and
  the synthetic result must not be read as proof of a real-user speedup.
- **Runtime dependency security:** the release lock set carries
  `pdfminer.six 20260107`, `Pillow 12.3.0`, and `cryptography 50.0.0`, with
  `pdfplumber 0.11.10` and `pypdfium2 5.13.0` in the validated runtime stack.
  The current default branch has Dependabot open alerts = 0.
- **Reproducible release inputs:** runtime, desktop, build, and test
  dependencies are installed from committed lock files by CI and the Windows
  release workflow.

## Known limitations

- `PERF-SHUTDOWN-002` remains **OPEN / NOT REPRODUCED** for active migration or
  mailbox-scan shutdown boundedness.
- Native GUI geometry remains a known non-gating failure lane.
- Native completion latency is **NOT MEASURED / OWNER-WAIVED**.
- Email completion remains **NOT MEASURED / DEFERRED** for this release topic.

## Upgrade and privacy notes

- Back up local data before upgrading:

```powershell
python -m scripts.invoice_fetch.backup_cli --reason before-upgrade
```

- Verify `SHA256SUMS.txt` for every downloaded release artifact.
- Do not upload `invoices.db`, real invoices, exported claim packages, mailbox
  credentials, API keys, or full tokenized URLs to public issues.
