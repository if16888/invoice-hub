# Invoice Hub v0.1.8 — Release notes

> Status: **Unreleased — previous candidate superseded.** No official v0.1.8
> annotated tag or GitHub Release has been created.

## Source boundary

- `0eb2b1a537d5ce38b0fc369c374eb32cb526ab3c` was a previous v0.1.8
  release-candidate/source-freeze attempt.
- That candidate is no longer the release authority for a future v0.1.8
  publication.
- The post-v0.1.8 development commit `33e8ffe` was not included in that
  candidate.

## What's changed

- Local import cancellation now stops at safe top-level source boundaries while
  preserving completed results and keeping the application responsive.
- Mailbox and invoice redownload work runs outside the GUI thread with explicit
  lifecycle and shutdown ownership.
- Review workbench, export safety, SQLite migration/backup, privacy gates, and
  release metadata checks are covered by the Windows GitHub CI lanes.

## Validation notes

- GitHub CI run `33522896246` passed source gates, all three unit-test shards,
  and HCI acceptance.
- Native GUI geometry remains a known non-gating host-specific failure lane.
- Users should verify `SHA256SUMS.txt` before installing and use synthetic or
  disposable data for first-run smoke testing.

## Known limitations

- Parsing results still require human review before reimbursement submission.
- The application remains local-first and does not provide cloud sync or direct
  enterprise expense-platform submission.
