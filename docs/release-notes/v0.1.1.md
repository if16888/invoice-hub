# Invoice Hub v0.1.1 - Windows x64

Patch release for the public feedback flow after v0.1.0.

## What's changed

- Desktop "Open GitHub Issues" now points to the public `if16888/invoice-hub` issue chooser.
- Added privacy-first GitHub Issue templates for bug reports and feature requests.
- Added a feedback privacy reminder before exporting diagnostics or opening GitHub Issues.
- README feedback guidance now separates ordinary issues from security/privacy vulnerability reports.

## Release artifacts

- `InvoiceHub-Setup-v0.1.1.exe`: Windows per-user installer, no administrator permission required.
- `InvoiceHub-windows-x64-v0.1.1.zip`: portable onedir package.
- `checksums.txt`: SHA256 checksums for both artifacts.

## Privacy reminder

Please do not upload real invoices, receipts, itineraries, bank slips, mailbox screenshots, SQLite databases, Excel reimbursement packages, mailbox authorization codes, API keys, cookies, or full download links to public issues.

Use the redacted diagnostics package generated by Invoice Hub when reporting bugs.
