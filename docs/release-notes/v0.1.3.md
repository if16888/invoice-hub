# Invoice Hub v0.1.3 - Windows x64

Stable release focused on release-readiness hardening, safer download semantics, and the latest UI polish for invoice review.

## What's changed

- Made email scan and download summaries more accurate, including mailbox-level failures, pending retry counts, and AI auth pause status.
- Fixed redownload semantics so duplicate-only cases do not falsely report a restored original file.
- Kept downloader and OFD handling safer by treating unsupported OFD records as manual-required instead of pushing them through PDF parsing.
- Added a current-session pause when AI authentication fails, so later scans do not keep hitting the same failing provider.
- Polished the right-side invoice detail panel and the left-side invoice table filter affordance.
- Added lightweight column filters for common invoice table fields while keeping the workflow local-first and privacy-safe.
- Preserved the existing local-first import, scan, duplicate handling, and export behavior.

## Release artifacts

- `InvoiceHub-Setup-v0.1.3.exe`: Windows per-user installer, no administrator permission required.
- `InvoiceHub-windows-x64-v0.1.3.zip`: portable onedir package.
- `checksums.txt`: SHA256 checksums for both artifacts.

## Deferred

The following items are intentionally not included in v0.1.3:

- Overseas receipt support.
- Multi-currency expense support.
- Bank statement or payment proof features.
- AI OCR or new AI parsing features.
- Full Excel advanced filtering or table features.
- Full-rescan GUI tools.
- Expanded proof-material association logic.

## Privacy reminder

Please do not upload real invoices, receipts, itineraries, bank slips, mailbox screenshots, SQLite databases, Excel reimbursement packages, mailbox authorization codes, API keys, cookies, or full download links to public issues.

Use the redacted diagnostics package generated by Invoice Hub when reporting bugs.
