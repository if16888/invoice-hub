# Invoice Hub v0.1.5-rc1 - Windows x64

## Release type

Release candidate for the 0.1.5 settings and mailbox workflow.

## What's changed

- Completed the unified desktop Design System v1.1 visual convergence across the primary workbench surfaces.
- Added the settings center and mailbox workflow foundations while preserving the existing local-first data model.
- Hardened PDF preview replacement and stale-load protection during rapid invoice switching.
- Centralized buyer-warning presentation and made workbench preferences use an explicit writable INI store with legacy migration.
- Added release-gate coverage for DPI geometry, privacy/public export checks, packaging contracts, and review-workbench regressions.

## Known limitations

- This RC still requires physical Windows acceptance for clean install, upgrade, uninstall, persistence, and 100%/125%/150% display scaling.
- Outlook-family mailboxes continue to require OAuth2/XOAUTH2; they are not presented as ordinary IMAP accounts.

## Upgrade and privacy notes

- Back up local data before upgrading:

```bash
python -m scripts.invoice_fetch.backup_cli --reason before-upgrade
```

- Keep invoices, databases, exported claim packages, authorization codes, API keys, and full tokenized URLs out of public issue reports.
- Verify `SHA256SUMS.txt` before installing a downloaded package.
