# 已知问题

本文件记录发布前仍需向用户说明的限制。新增问题时请写清影响范围、规避方式和计划处理阶段。

## MVP 范围限制

- 网页链接下载依赖目标网站页面结构，遇到登录、验证码、一次性链接过期或页面改版时可能需要用户手动下载后再导入。
- OFD、图片和扫描件的解析能力仍有限；无法识别时应作为待补全记录，由用户手动确认字段。
- 手机扫码上传基于局域网访问，手机和电脑需要处于可互通的同一网络。
- 证明材料目前以发票或报销组附件方式管理，不是完整的企业级档案系统。

## 测试状态

发布前以 `docs/release-checklist.md` 中的验证命令为准。若完整回归测试出现历史失败，必须在发布说明中记录失败测试、原因和规避方式。
