# Settings / Preview Semantic Release Note

Settings credential and AI-key status messages now render as plain text with
semantic Design v1 tones instead of relying on embedded rich-text colors.

The document preview toolbar now uses the same token authority as the rest of
the UI and provides explicit normal, hover, keyboard-focus, pressed, and
disabled states.

No page hierarchy, navigation structure, or reimbursement workflow behavior is
changed by this work.
