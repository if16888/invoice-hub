# 二级页面与弹窗的桌面风格统一

本轮沿用 `design-v1.4-desktop`，将前一轮的苹果桌面风格扩展到设置子页、导入任务、审核报销信息及任务弹窗。采用系统字体、实色分组表面和清楚的动作层级；平台的标题栏和系统文件选择器继续使用原生行为。

## 覆盖范围

- 邮箱、开票信息、AI 配置、运行状态、安全与隐私、数据备份、关于七个设置子页；同时检查 AI 已配置与空状态。
- 本地导入、手机上传空闲页、审核的报销信息标签和专注预览。
- 邮箱、AI 服务、API Key、发票字段、财税字段、报销事由、公司开票信息、抬头设置、日期范围、材料共享、疑似重复复核、商户分类记忆、重复文件详情和日志窗口。
- 标准确认框、短文本输入框、列筛选浮层和日期日历。

## 统一规则与修正

1. 共用 `dialog_shell.py` 与 `dialog_form.py`，使用 24px 外边距、明确标题和辅助说明；表单分组白底，操作区使用细分隔线。
2. 取消在左、主要动作在右，通过按钮盒的布局提示保留原有信号和返回值。危险操作保留红色语义；消息框的 Cancel/No 默认选择由调用方决定，不自动改成确认。商户记忆删除不会成为默认回车动作。
3. 表单按当前内容计算初始高度。小屏或缩放时只滚动表单，操作区保持可见；财税字段的“未采集”、已知空值和实际金额继续保持原有区别。
4. 输入、按钮、勾选/部分勾选、禁用、焦点、日期下拉和数字调节器使用统一尺寸与状态。补齐深浅色复选框、调节箭头和日历导航。
5. 设置使用灰色工作区与白色分组内容。备份操作分行排列；新增邮箱采用相同主操作样式。常用/高级分组标题在行背景之后绘制，避免被选中背景覆盖。
6. 手机上传复用已有 `AdaptiveStackedWidget`，按当前状态提供尺寸；空闲任务使用内容高度，活动会话继续保留扩展空间。报销信息标签的内容与视口统一为内容表面。

没有修改发票审核、财税校验、材料关联、重复判定、凭据保存或导出规则，也没有新增第三方依赖。

## 本地验证

- 本轮 42 个相关模块、264 项测试通过；补跑与 subtests 不重复累计。逐模块结果位于交付目录 `apple-subpages-20261106/validation.json`。
- 验证了回车保存、Escape 取消、危险操作默认取消、未知财税值与空值的区别、表单自然高度、小窗口操作区、导航标题实际绘制和手机空闲任务高度。
- 覆盖手机上传界面、权限操作与诊断、专注预览、鼠标归组和快捷键归组。完整 HCI 19/19 通过，无残留线程或应用进程。
- 使用隔离合成数据采集 32 个页面/弹窗状态，包含浅色 100%、深色 125% 与浅色 150%。缩放检查使用独立的虚拟桌面配置；按钮边界记录随截图交付。
- 这些是 Linux Qt 离屏验证。实体 Windows 的系统字体、原生窗口、真实 DPI、读屏和高对比度仍需在 Windows 上验证，不替代发布验收。
- 隐私、公开源码树、发布元数据、架构、SVG XML、Python 编译和 `git diff --check` 门禁通过。

本轮工作留在 `design/desktop-visual-polish`，未创建发布标签或 Release。
