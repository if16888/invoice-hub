# 用户快速开始

Invoice Hub 用于提交报销前的个人材料整理。推荐先用少量样本试跑，再导入完整邮箱或本地目录。

## 1. 启动桌面端

开发环境：

```powershell
pip install -r requirements.txt
pip install -r requirements-desktop.txt
python -m scripts.invoice_fetch desktop
```

发布包环境：运行安装后的 `Invoice Hub` 快捷方式，或打开 portable zip 中的 `InvoiceHub.exe`。

## 2. 系统设置（配置中心）

点击主界面右上角的**系统配置**即可打开配置中心。

### 邮箱账号配置
- 点击“新增邮箱账号”，按照 3 步向导配置：
  1. 选择邮箱类型（支持 QQ 邮箱、163/126 网易邮箱、自定义 IMAP）。
  2. 输入邮箱地址与授权码/密码（程序会自动写入系统凭据管理器进行安全存储，并不写入配置文件）。
  3. 执行连接测试以验证配置是否正确。
- 列表支持添加并管理多个邮箱，你可以通过勾选复选框单独“启用/停用”邮箱扫描，或对其进行“编辑”和“删除”。

### AI 模型配置
- 切换到“AI 模型”页签，点击“新增 AI 配置”：
  1. 选择 AI 供应商（DeepSeek 或 Gemini）并为该配置起一个易记的名称。
  2. 填写所需的模型名称及 API Key（密钥将安全存入系统凭据管理器）。
  3. 点击测试，然后选择“仅保存配置”或“保存并设为当前”。
- 列表支持保存多个 AI 配置，可一键点击“设为当前”来切换当前生效的模型，也可通过“停用”按钮全局关闭 AI 自动分类提取。

## 3. 导入材料

可选入口：

- `导入发票`：选择本地目录，导入 PDF/OFD/图片/ZIP。
- `扫描邮箱`：读取已启用的 IMAP 邮箱中的候选发票邮件。
- `扫码上传`：在局域网中打开手机上传页，上传手机里的发票或证明材料。

本地导入会复制文件到运行时目录，不会移动原始文件。

## 4. 审核与补全

在左侧列表选择发票后，右侧可编辑：

- 发票号码
- 开票日期
- 销售方名称
- 发票金额
- 消费类型
- 用户备注

解析不完整的记录会显示为 `待补全` 或 `未识别`。导出前建议补齐金额、日期、销售方和分类。

## 5. 关联报销组并导出

在 `报销导出` 页签中新建或选择报销组，将已确认的发票关联进去，再导出报销组附件包。

导出包通常包含：

- Excel 台账
- manifest
- 发票原件副本
- 已关联的证明材料

## 6. 反馈问题

菜单 `更多` 中提供：

- 打开日志目录
- 复制诊断信息
- 导出脱敏诊断包
- 打开 GitHub Issues

请只上传脱敏诊断包，不要上传真实发票、Excel 报销包、数据库、邮箱授权码、API Key 或完整下载链接。
