# 日常报销流程修复

本轮针对 master 074fadc 的使用审查，分两次提交修正：

- 归组后保持已加载范围、当前发票和行位置。
- 导出缺件行双击按 ID 打开对应记录，并提供返回报销组入口；不依赖首批 50 行。
- 隐藏工作台不运行 HCI 统计；可见工作台复用本次指标快照；缺证明和购买方异常使用数据库筛选计数。
- 一次导出页刷新复用材料检查结果，20 张样本的原件检查从 70 次减少到 20 次；最终导出仍重新校验文件。
- 导出范围在检查前选择，缺口和按钮按同一范围更新，确认框保持该范围。全组汇总另标为“全组问题项”。
- 此票归属展示实际关联，不再把加入目标误显示为已归属。
- 从导出返回选票时清除旧筛选；连续审核 G 和普通 Ctrl+G 都走单票非模态归组。
- 工作台区分“缺证明”和“待补全”；当前状态展示区改名“当前概况”。
- 无邮箱时直接提供“添加邮箱”入口。
- 小屏列宽保留报销组列可见，批量按钮统一最低高度。

回归包含归组身份保持、旧发票定位、材料检查次数、隐藏刷新、数据库计数、小屏列可见，以及混合状态报销组切换导出范围后的阻断状态。

Linux 离屏验证不替代 Windows 100%/125%/150% DPI、真实邮箱/手机和原生安装包验收。本轮不创建发布 tag 或 Release。
